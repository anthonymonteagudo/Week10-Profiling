Texture compression changes sampled values

This means: Block compression stores texels in small encoded blocks.

Lecture slide 82.

A texel is the texture equivalent of a data sample. Compression encodes many samples into fewer bits. Lossy compression reconstructs approximate values, and multiplying those values can reveal errors that were subtle before. These are Simon schreibt’s source comparisons, not a capture from our lounge. In BC1, a block uses quantized endpoint colors and indices to reconstruct a small palette. The familiar red/green/blue 5:6:5 description concerns the endpoint representation, not every texture format or a direct independent bit budget for every pixel. BC4, BC5, BC7 and other formats have different purposes and behavior. In Unreal, record the target platform, actual format, Compression Settings, sRGB and Resource Size. Test a duplicate texture and preserve the relevant mask or color values. PNG or TGA describes a source-file container; it does not by itself specify the cooked GPU format. An eight-bit unsigned channel has 256 possible code values. The source’s eight-bit/128-color note is an error, and vertex color is not automatically a lower-memory replacement for a texture.

Inspect in Unreal: On a duplicate texture, record Compression Settings, sRGB, actual target format, mip policy and Resource Size. Compare an amplified material output as well as the normal view. Keep the original texture.

Check yourself: Would changing the source PNG alone fix the GPU format?

Padding protects filtered texture edges

This means: Padding extends useful border color beyond a UV island or cutout.

Lecture slide 83.

Filtering combines nearby texture samples. Mip generation also combines information into smaller levels. Padding, often created by dilation, extends suitable border values outside an island or visible cutout so unrelated colors are less likely to enter the filtered result. Here the source scene shows a foliage-edge problem and the other image shows the source texture in a viewer. They are related source illustrations, not a measured before-and-after fix. Correct alpha does not guarantee that the RGB values around the cutout are suitable. Dilation means expanding neighboring useful values into that surrounding region. A mip is a prefiltered lower-resolution image level. In Unreal, inspect the color and alpha separately, lower mip levels, the blend mode, opacity-mask cutoff and material sampling. Check close, distant and moving views. The required padding depends on the layout, filtering and mip range, so one fixed pixel count is not a universal solution. Turning mipmaps off can replace a halo with aliasing and unstable detail; confirm the intended filtering instead. These are source examples rather than current UE measurements.

Inspect in Unreal: Inspect RGB, alpha and lower mip levels, then test close/distant camera motion. Keep material blend mode and opacity cutoff recorded. Change the border data on a test copy rather than disabling mipmaps as a blanket fix.

Check yourself: Why can a clean close-up still develop a distant halo?

Texel density connects detail to world scale

This means: Texel density is the amount of texture detail per unit of surface distance.

Lecture slide 84.

A texel is a texture sample. Texel density relates the texture’s samples to distance along the world-space surface, commonly expressed as texels per meter. It is different from screen pixels, because camera distance changes screen coverage. The source scene deliberately mixes sharpness and apparent brick scale, while its reference image specifies one chosen brick width. Those are teaching examples, not a requirement that all bricks be thirty centimeters wide or every asset share one exact density. With the same texture and UV mapping, uniformly doubling the object’s world size halves texels per meter. Scaling the UVs to repeat more often can restore density for a tiling material, but a unique atlas has different constraints. In Unreal and the DCC, check mesh scale, UV channel, tiling, imported resolution and effective texture limits. A checker reference helps compare objects, but also inspect whether bricks or other recognizable features have plausible physical size. Choose density by the project’s viewing distance, art direction and memory budget. Consistent density is not an instruction to raise every texture to the largest size.

Inspect in Unreal: Compare a checker on a known-size reference and your prop. Record UV tiling, texture resolution, mesh scale and viewing distance. Check physical feature size before increasing the texture budget.

Check yourself: What happens to density if the prop becomes twice as large?

Mipmaps, stored size and residency

This means: A mip is a prefiltered, lower-resolution image level of the same texture. A texel is one data sample in that image; a screen pixel belongs to the output view.

The source deliberately edits a small mip level to make its selection visible. It demonstrates stored levels, rather than a recommended default texture appearance or an Unreal import workflow. The old DDS/Photoshop instructions are source context.

Doubling width and height quadruples the texel count. At the same format and comparable mip policy, storage scales approximately the same way. A complete ideal 2D power-of-two mip chain adds about one third to its top level. Streaming may retain only the levels needed in memory; a smaller on-screen view does not automatically shrink the stored asset.

Inspect in Unreal: Compare imported dimensions, mip count, Max Texture Size, LOD Bias and Resource Size, then examine residency with stat streaming. Record the platform and actual format. These are different counters.

Power-of-two means dimensions such as 256, 512 or 1024. Modern graphics APIs support non-power-of-two textures with mip levels, but Unreal’s streaming, import and compression paths have specific requirements. Check the asset and engine version.

Wrap repeats; Clamp extends the edge

This means: A sampler address mode decides which texture data to use when UV coordinates leave the usual 0–1 range.

In Simon’s illustration, drawing to the image border makes the line continue when Clamp extends that edge value. Wrap instead repeats the texture. These are the source’s illustration stages, rather than our current UE scene.

Inspect in Unreal: On a duplicate test texture, compare X/Y addressing while moving UVs outside 0–1. Check the material’s Sampler Source, because a shared sampler may select its own addressing behavior. Keep filtering and mip settings matched. A Clamp math node that restricts a number is a separate operation.

One position can need several render vertices

This means: Rendering needs consistent attribute records: position, normal, UVs and other data. Corners at one position can require separate records when their attributes differ.

The smooth cube, hard-normal cube and hard-normal cube with UVs have matching eight positions and twelve triangles. Their referenced attribute-tuple counts are 8, 24 and 24. Run python GeometryInspection/inspect_obj.py from the kit root. Adding UVs need not split records already separated by hard normals.
