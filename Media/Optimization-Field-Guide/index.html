Texture compression changes sampled values

This means: Block compression stores texels in small encoded blocks.

Lecture slide 87.

A texel is the texture equivalent of a data sample. Compression encodes many samples into fewer bits. Lossy compression reconstructs approximate values, and multiplying those values can reveal errors that were subtle before. These are Simon schreibt’s source comparisons, not a capture from our lounge. In BC1, a block uses quantized endpoint colors and indices to reconstruct a small palette. The familiar red/green/blue 5:6:5 description concerns the endpoint representation, not every texture format or a direct independent bit budget for every pixel. BC4, BC5, BC7 and other formats have different purposes and behavior. In Unreal, record the target platform, actual format, Compression Settings, sRGB and Resource Size. Test a duplicate texture and preserve the relevant mask or color values. PNG or TGA describes a source-file container; it does not by itself specify the cooked GPU format. An eight-bit unsigned channel has 256 possible code values. The source’s eight-bit/128-color note is an error, and vertex color is not automatically a lower-memory replacement for a texture.

Inspect in Unreal: On a duplicate texture, record Compression Settings, sRGB, actual target format, mip policy and Resource Size. Compare an amplified material output as well as the normal view. Keep the original texture.

Check yourself: Would changing the source PNG alone fix the GPU format?

Padding protects filtered texture edges

This means: Padding extends useful border color beyond a UV island or cutout.

Lecture slide 88.

Filtering combines nearby texture samples. Mip generation also combines information into smaller levels. Padding, often created by dilation, extends suitable border values outside an island or visible cutout so unrelated colors are less likely to enter the filtered result. Here the source scene shows a foliage-edge problem and the other image shows the source texture in a viewer. They are related source illustrations, not a measured before-and-after fix. Correct alpha does not guarantee that the RGB values around the cutout are suitable. Dilation means expanding neighboring useful values into that surrounding region. A mip is a prefiltered lower-resolution image level. In Unreal, inspect the color and alpha separately, lower mip levels, the blend mode, opacity-mask cutoff and material sampling. Check close, distant and moving views. The required padding depends on the layout, filtering and mip range, so one fixed pixel count is not a universal solution. Turning mipmaps off can replace a halo with aliasing and unstable detail; confirm the intended filtering instead. These are source examples rather than current UE measurements.

Inspect in Unreal: Inspect RGB, alpha and lower mip levels, then test close/distant camera motion. Keep material blend mode and opacity cutoff recorded. Change the border data on a test copy rather than disabling mipmaps as a blanket fix.

Check yourself: Why can a clean close-up still develop a distant halo?

Texel density connects detail to world scale

This means: Texel density is the amount of texture detail per unit of surface distance.

Lecture slide 89.

A texel is a texture sample. Texel density relates the texture’s samples to distance along the world-space surface, commonly expressed as texels per meter. It is different from screen pixels, because camera distance changes screen coverage. The source scene deliberately mixes sharpness and apparent brick scale, while its reference image specifies one chosen brick width. Those are teaching examples, not a requirement that all bricks be thirty centimeters wide or every asset share one exact density. With the same texture and UV mapping, uniformly doubling the object’s world size halves texels per meter. Scaling the UVs to repeat more often can restore density for a tiling material, but a unique atlas has different constraints. In Unreal and the DCC, check mesh scale, UV channel, tiling, imported resolution and effective texture limits. A checker reference helps compare objects, but also inspect whether bricks or other recognizable features have plausible physical size. Choose density by the project’s viewing distance, art direction and memory budget. Consistent density is not an instruction to raise every texture to the largest size.

Inspect in Unreal: Compare a checker on a known-size reference and your prop. Record UV tiling, texture resolution, mesh scale and viewing distance. Check physical feature size before increasing the texture budget.

Check yourself: What happens to density if the prop becomes twice as large?

Mipmaps, stored size and residency

This means: A mip is a prefiltered, lower-resolution image level of the same texture. A texel is one data sample in that image; a screen pixel belongs to the output view.

The source deliberately edits a small mip level to make its selection visible. It demonstrates stored levels, rather than a recommended default texture appearance or an Unreal import workflow. The old DDS/Photoshop instructions are source context.

Doubling width and height quadruples the texel count. At the same format and comparable mip policy, storage scales approximately the same way. A complete ideal 2D power-of-two mip chain adds about one third to its top level. Streaming may retain only the levels needed in memory; a smaller on-screen view does not automatically shrink the stored asset.

Inspect in Unreal: Compare imported dimensions, mip count, Max Texture Size, LOD Bias and Resource Size, then examine residency with stat streaming. Record the platform and actual format. These are different counters.

Power-of-two means dimensions such as 256, 512 or 1024. Modern graphics APIs support non-power-of-two textures with mip levels, but Unreal’s streaming, import and compression paths have specific requirements. Check the asset and engine version.

Wrap repeats; Clamp extends the edge

This means: A sampler address mode decides which texture data to use when UV coordinates leave the usual 0–1 range.

In Simon’s illustration, drawing to the image border makes the line continue when Clamp extends that edge value. Wrap instead repeats the texture. These are the source’s illustration stages, rather than our current UE scene.

Inspect in Unreal: On a duplicate test texture, compare X/Y addressing while moving UVs outside 0–1. Check the material’s Sampler Source, because a shared sampler may select its own addressing behavior. Keep filtering and mip settings matched. A Clamp math node that restricts a number is a separate operation.

LOD coloration and screen-size thresholds

This means: LOD coloration identifies the active conventional level of detail.

Lecture slide 53. Source UI is older than the UE 5.7 lab.

LOD means level of detail: a representation selected to reduce unnecessary detail. The source’s coloration identifies active conventional mesh levels, while the mesh editor exposes screen-size settings. Colors identify a selected level rather than a performance verdict. For an ordinary descending screen-size chain, increasing a coarser level’s transition threshold generally allows it to appear while the object is larger on screen; lowering that threshold keeps the finer level to a smaller projected size. Test Auto along the real camera route, because bounds, FOV, quality settings and forced/minimum LOD policies affect the result. The source’s 0.5 value is an example, not a universal recommendation. Nanite detail selection is a separate path: these conventional LOD colors are not a Nanite cluster-cost measurement. Preserve the required silhouette and inspect motion before timing. These are source captures, not a newly rehearsed classroom LOD result.

Check yourself: Does a coarser LOD appear at the distance you intended?

Grouping, instancing and merging

This means: A merged mesh changes the rendering unit; an editor group changes selection.

Lecture slide 56. Source UI is older than the UE 5.7 lab.

An editor group lets us select related actors together. Instancing reuses compatible geometry with per-instance data. Mesh merging creates a new combined asset. Material sections remain important: one merged actor does not guarantee one draw across all passes. The source image shows a selected modular tent with many actors, not a measured 31-to-one draw-call result. The transcript’s simplified arithmetic should not be treated as a portable counter. In Unreal’s Merge Actors settings, choose the merge type deliberately. Merging geometry, batching identical components and baking materials are different operations. Choose a pivot and preserve transforms; inspect collision, UVs and LOD policy. Broader bounds or merged sections can reduce culling granularity, and material baking can change UV or position-dependent shading. Keep source actors in a separate duplicate/control. Ensure that only one treatment is present in the measured map so hidden duplicate geometry does not invalidate the comparison. Record actual submissions, CPU/render timing and frame time, and inspect a second view. HLOD uses a coarser representation for distant regions, which the following Fortnite case illustrates.

Check yourself: What could one large merged bound keep visible?

Lightmap density and bake resolution

This means: Lightmap density compares baked-lighting texels with world-space surface area.

Lecture slide 60. Source UI is older than the UE 5.7 lab.

A lightmap stores precomputed lighting. Lightmap density visualizes how much of that lighting texture covers a world-space surface; it is separate from the ordinary color-texture density introduced later. Its colors depend on configured density targets and the legend. Blue is not automatically good, and red is not a universal error. Min Lightmap Resolution is a UV generation/repacking target that influences chart padding. It is distinct from the default Lightmap Resolution and a placed component’s override. Light Map Coordinate Index chooses the lightmap UV channel. In a compatible precomputed-lighting test, changing relevant geometry or lighting can invalidate the bake. A valid matched measurement needs the intended built state. Preview/Production quality settings change build quality and sampling; they do not simply replace the authored lightmap dimensions. The source’s choices such as 16 or 64 are specific to those objects and that scene. The current lounge uses a different Lumen/SM6 path and is not a completed baked-lighting counterpart. Do not apply an unconditional lighting-rebuild workflow to every dynamic scene. In a separate compatible map, rebuild and inspect contact, seams and motion-sensitive requirements before accepting the budget.

Check yourself: Does a higher bake-quality preset change the texture dimensions?

Cull Distance Volumes and actor bounds

This means: A Cull Distance Volume assigns eligible components a distance limit from their bounds size.

Lecture slide 63. Source UI is older than the UE 5.7 lab.

Distance culling stops drawing eligible content beyond a chosen range. It differs from frustum rejection and occlusion behind another surface. A Cull Distance Volume assigns size/distance pairs to eligible components inside it. In the installed UE 5.7 source, matching uses the component’s bounds-sphere diameter and its component location; the relevant path requires Static mobility and Allow Cull Distance Volume. The pairs choose a nearest size entry rather than a linear interpolation. A zero distance entry can mean no distance cull for that assigned group; inspect the effective component value rather than extrapolating a universal rule for overlapping policies. The figure is Epic documentation UI, not a prepared volume in our lounge. Its default/example numbers are not class defaults. Check Current Max Draw Distance, component settings and the intended game/standalone route. Editor Game View hides editor helpers; it is not the same thing as launching gameplay. For Nanite, use supported detail/visibility diagnostics rather than assuming every conventional distance setting behaves identically. Preserve focal landmarks and interaction cues, record the changed workload, disable diagnostic views before timing, and restore any temporary FreezeRendering toggle. No new local volume experiment is claimed.

Check yourself: Could merging these props change which distance pair they receive?

Particle coverage and translucent layers

This means: Overlapping translucent cards can shade the same screen region repeatedly.

Lecture slide 80. Source UI is older than the UE 5.7 lab.

A translucent card blends its shaded contribution with what is behind it. Repeated overlapping coverage can shade the same region more than once. Spawn rate is the number of new particles emitted per unit time; lifetime also affects how many remain active. The workshop compares a higher sand-emitter rate with a lower rate. Those figures are source Shader Complexity views, not our GPU timings or a matched promise of a particular saving. The lower density also changes the visible effect. Record camera, card size, material, lifetime and spawn policy. In Niagara, inspect the corresponding spawn/update modules and renderer rather than expecting the old Cascade UI. Shader Complexity and Quad Overdraw are different diagnostics; neither is a complete GPU timer. A green water material is not proof of cheap water: Opaque can avoid a transparency path while other shading, reflection or simulation work remains. Return to Lit, disable overlays, preserve the required gust and compare the relevant pass plus frame time. Turning off ShowFlag.Particles hides rendering without proving particle simulation stopped.

Check yourself: Would fewer particles preserve the gust as the camera moves through it?

Unused alpha and texture resource cost

This means: An alpha channel stores another signal; its memory cost depends on the chosen GPU format.

Lecture slide 93. Source UI is older than the UE 5.7 lab.

Alpha is a fourth texture channel that can carry opacity or another mask. Its cost depends on encoding. In the common BC1 versus BC3 comparison, a 4-by-4 block occupies 8 versus 16 bytes, but BC7 and other formats have different behavior. Removing alpha does not guarantee a format change or halve every resource. The workshop reports about 683 versus 1365 KB for its particular 1K source setup; this screenshot directly shows the alpha-bearing texture and DXT5 format, not a matched two-texture capture. We do not treat the source’s displayed units as a new course measurement. In Unreal, inspect Compression Settings, Compress Without Alpha, sRGB, actual target format, mip policy and Resource Size on a duplicate. Confirm that no used material channel, instance override or runtime variant depends on the removed signal. Replacing a texture and simplifying shader logic are separate changes; identical instruction counts do not imply identical texture memory. Many actors can share one resident texture resource, so texture bytes do not automatically multiply once per rock. Count unique resources and residency. Correcting a missing normal map can restore the intended appearance even when an optimization removes another unused feature. Use the mistake as evidence for a repeatable validation check, not a reason to blame the author.

Check yourself: Would removing an unused alpha always halve memory?

UV channels can carry more than color

This means: A UV channel is a coordinate/data set; a nested function can read a channel that the top-level graph does not visibly use.

The source finds channel 3 inside a wind function. An unchanged preview after deletion does not prove that all LODs, material variants, platforms, baked-lighting or animation users are safe. Deletion can renumber later channels. Audit users and test a duplicate across all required states before accepting removal. No new local deletion/import experiment was run.

Reflection capture versus Lumen

This means: A reflection capture stores a cubemap for the reflection environment. Lumen uses its configured tracing and reconstruction path.

Check the active reflection method before interpreting a source probe layout. Stored resolution/count, screen influence and visible contribution answer different questions. A crash anecdote is not a hardware-independent overlap budget. Inspect actual resources, logs and image quality; the source view is not a new Lumen benchmark.

Read the surface input you need

This means: Buffer visualization displays a selected material/rendering quantity rather than the final Lit image.

Use Roughness for the roughness input, World Normal for shading direction, and Base Color for surface color. Detail Lighting is a neutral lighting diagnostic retaining normal-map detail; it does not isolate every original roughness value. Read the legend and return to Lit before judging the intended result or timing it. Editor Game View hides helpers; it is not gameplay.
