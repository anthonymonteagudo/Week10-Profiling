From finding to tested change

Custom Optimization View

In Unreal: Tools → Week 10 Optimization → Toggle Custom Optimization View.

The editor overlay draws colored candidate bounds over the current viewport. It does not replace engine shaders or register a new engine ViewMode enum. No materials, visibility flags or level properties are changed.

Enable viewport Realtime. Toggle again to refresh cached actor bounds after edits. Disable the overlay before collecting timings. Changing maps disables it. The overlay draws at most the configured actor limit; the dashboard retains every finding.

Inspect the actor

Use a row's “Copy select command” and paste into Unreal's Python console. The command selects the actor only when it is loaded in the current world. The webpage does not execute commands in Unreal.

  1. Read the rule, observed property and policy.
  2. Check one intentional exception or known-good actor.
  3. Name the visual requirement and expected timing change.
  4. Change one property in a writable test copy.
  5. Disable diagnostics, return to Lit, repeat the capture, and compare appearance.
